# 配對遊戲題目對照表

- **對應任務**：T05 介面與遊戲題目設計（8 題題目與「答案 → 配對欄位」對照表）
- **使用者**：前端（T10 小遊戲，題目檔 `frontend/src/data/matchGameQuestions.js`）、PM／AI（T13 推薦）
- **狀態**：已確認（2026-11-26）。欄位名稱與英文值照 [新增 API 契約 §1](../api/新增API契約.md)，不可更改。題目有異動時直接改這份文件，並同步更新前端題目檔與測試。

## 流程

答完 8 題後，前端依序：

1. 把每題選項的「寫入的值」合併，呼叫三支既有 API 寫入配對欄位：

   | 題 | API | 欄位 |
   |---|---|---|
   | q1–q3 | `PUT /api/matching/profile/lifestyle` | `activityLevel`、`availableTime`、`housingType` |
   | q4 | `PUT /api/matching/profile/experience` | `petOwnershipExperience` |
   | q5–q8 | `PUT /api/matching/profile/environment` | `hasChildren`、`hasOtherPets`、`noiseSensitive`、`hasAllergies` |

2. 加總每個選項的毛孩類型加分，得出毛孩類型（見[計分規則](#計分規則)）。
3. 呼叫 `PUT /api/matching/profile/game`，保存 8 題答案（`{ questionId: "q1", optionId: "A" }`）和 `petType`。

## 毛孩類型

| `petType.code` | `label` | `description` |
|---|---|---|
| `outdoor-buddy` | 戶外冒險型 | 適合活動量高、喜歡出門散步和玩耍的毛孩 |
| `balanced-buddy` | 隨和陪伴型 | 適合個性穩定、能配合家人作息的毛孩 |
| `couch-buddy` | 居家宅宅型 | 適合安靜、喜歡待在家陪你的毛孩 |

代碼一律用小寫，與契約和前端計畫的寫法一致。

## 題目

| 題 | 題目 | 選項 | 寫入的值 | 毛孩類型加分 |
|---|---|---|---|---|
| q1 | 週末早上你通常在做什麼？ | A 出門爬山或運動 | `activityLevel: "high"` | `outdoor-buddy` +2 |
| | | B 在家追劇放鬆 | `activityLevel: "low"` | `couch-buddy` +2 |
| | | C 看心情 | `activityLevel: "medium"` | `balanced-buddy` +2 |
| q2 | 下班或下課後，每天能陪毛孩多久？ | A 兩小時以上 | `availableTime: "extensive"` | `outdoor-buddy` +1 |
| | | B 一小時左右 | `availableTime: "moderate"` | `balanced-buddy` +1 |
| | | C 很少，常常很晚回家 | `availableTime: "minimal"` | `couch-buddy` +1 |
| q3 | 你現在住在哪裡？ | A 有院子的透天 | `housingType: "house-with-yard"` | `outdoor-buddy` +1 |
| | | B 沒院子的透天 | `housingType: "house-no-yard"` | `balanced-buddy` +1 |
| | | C 公寓、大樓或套房 | `housingType: "apartment"` | `couch-buddy` +1 |
| q4 | 你養過寵物嗎？ | A 養過好幾隻 | `petOwnershipExperience: "experienced"` | `outdoor-buddy` +1 |
| | | B 養過一兩隻 | `petOwnershipExperience: "intermediate"` | `balanced-buddy` +1 |
| | | C 從來沒養過 | `petOwnershipExperience: "none"` | `couch-buddy` +1 |
| q5 | 家裡有小孩嗎？ | A 有 | `hasChildren: true` | `balanced-buddy` +1 |
| | | B 沒有 | `hasChildren: false` | 不加分 |
| q6 | 家裡還有其他寵物嗎？ | A 有 | `hasOtherPets: true` | `balanced-buddy` +1 |
| | | B 沒有 | `hasOtherPets: false` | 不加分 |
| q7 | 住的地方需要特別安靜嗎？（例如鄰居會在意吵鬧聲） | A 需要 | `noiseSensitive: true` | `couch-buddy` +1 |
| | | B 還好 | `noiseSensitive: false` | 不加分 |
| q8 | 你或家人會對貓過敏嗎？ | A 會 | `hasAllergies: true` | 不加分 |
| | | B 不會 | `hasAllergies: false` | 不加分 |

- q1–q4 有 A、B、C 三個選項，q5–q8 只有 A、B 兩個選項。
- 每個欄位只由一題決定，沒有兩題寫同一個欄位。
- 契約與資料庫還有其他可用值（例如 `housingType` 的 `condo`、`townhouse`，`petOwnershipExperience` 的 `beginner`），遊戲不使用。

## 計分規則

1. 加總 8 題的加分，分數最高的類型就是結果。
2. 同分時依 **隨和陪伴型 → 戶外冒險型 → 居家宅宅型** 的順序決定。

範例（可直接當測試資料）：

| 答案 | 戶外 | 隨和 | 宅宅 | 結果 |
|---|---|---|---|---|
| q1 C、q2 C、q3 C、q4 B、q5 B、q6 B、q7 A、q8 B | 0 | 3 | 3 | 隨和陪伴型（同分，隨和優先） |
| q1 A、q2 C、q3 C、q4 A、q5 B、q6 B、q7 A、q8 B | 3 | 0 | 3 | 戶外冒險型（同分，戶外優先於宅宅） |
| 全部選 A | 5 | 2 | 1 | 戶外冒險型 |

## 對推薦的影響

依 [新增 API 契約 §0](../api/新增API契約.md) 的 Top 3 硬條件：

- q5 選「有」：推薦會排除 `personality.goodWith.children = false`（不適合小孩）的動物。
- q6 選「有」：推薦會排除 `personality.goodWith.otherPets = false`（不適合其他寵物）的動物。
- q8 選「會」：推薦裡完全不會出現貓（`species = cat`）。所以 q8 一定要明確問「對貓過敏」，不能只問「會不會過敏」。
- 動物的 `goodWith` 沒填（`null`）時不會被排除，改由計分扣分並寫進 `cautions`。
