# FastAPI 骨架 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 FastAPI 取代 `backend/`：跑在 `:5000`、連上 MongoDB Atlas、提供健康檢查與 Swagger，CI 改跑 pytest；舊 Node 後端移到 `backend-legacy/`。

**Architecture:** `app/main.py` 建立 FastAPI app，在 lifespan 中用 PyMongo 的 `AsyncMongoClient` 連線與關閉。設定由 `pydantic-settings` 從 `backend/.env` 讀取。`responses.py` 把所有錯誤統一成 `{ success: false, message }`。根目錄 npm 指令透過 `scripts/py.js` 呼叫 `backend/.venv` 裡的 Python，Windows 和 Linux 寫法相同。

**Tech Stack:** Python 3.11+（本機 3.14）、FastAPI、uvicorn、PyMongo（async API）、pydantic-settings、pytest、httpx。

**Spec:** [後端改用 FastAPI：骨架與遷移規格](../specs/2026-11-25-後端改用FastAPI-design.md)

**分支：** 從 `dev` 開 `chore/fastapi-skeleton`。需求文件沒有對應的任務編號，PR 標題用 `[chore] 後端改用 FastAPI 骨架`。

## Global Constraints

- 埠號 `5000`，固定寫在啟動指令 `--port 5000`。
- Swagger：`docs_url="/api-docs"`、`openapi_url="/api-docs.json"`。
- 成功回應 `{ "success": true, "data": ... }`；失敗回應 `{ "success": false, "message": "<繁體中文>" }`。
- 驗證錯誤回 400（不是 FastAPI 預設的 422）。
- 環境變數只有 `MONGODB_URI`（必填）、`MONGODB_DB`（預設 `pet_haven`）、`CORS_ORIGINS`（預設 `http://localhost:3000`，逗號分隔）。
- `.env` 不進 repo，也不讀取內容；只能用 `mv` 搬移檔案。
- 單元測試不連 Atlas，也不連任何真的資料庫。
- CI 不連 Atlas，用 `mongo:5.0` service，`MONGODB_DB=pet_haven_test`。
- commit 訊息用 `feat:`／`chore:`／`docs:`／`ci:` 開頭，內容用繁體中文，結尾加 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`。

## Review Focus

- 舊的 `backend/.env` 還有 `JWT_SECRET`、`NODE_ENV` 等 Node 用的變數：新後端要能正常啟動（`extra="ignore"`）→ Task 2 `test_settings_ignore_unknown_keys`
- Atlas 連不上（IP 不在白名單、密碼錯誤）：伺服器照常啟動，`/api/ready` 約 5 秒內回 503，不能卡 30 秒 → Task 2 `test_is_db_ready_false_on_error`＋`serverSelectionTimeoutMS=5000`；Task 5 實測
- `CORS_ORIGINS` 有空白或多個來源（`http://a, http://b`）：每個都要允許 → Task 2 `test_cors_origin_list_strips_spaces`、`test_cors_preflight_allows_frontend`
- 沒先執行 `npm run setup` 就執行 `npm run dev:backend`：要顯示中文提示，不能只丟出 Node 錯誤堆疊 → Task 1 Step 6
- 程式中出現未處理的例外：回 500 與統一格式，不能洩漏錯誤堆疊 → Task 2 `test_unhandled_error_returns_500`

- Produces:
  - `app.config.Settings(BaseSettings)`：`mongodb_uri: str`（必填）、`mongodb_db: str = "pet_haven"`、`cors_origins: str = "http://localhost:3000"`；`model_config = SettingsConfigDict(env_file=".env", extra="ignore")`；方法 `cors_origin_list() -> list[str]`（逗號切開、去掉空白、忽略空字串）。
  - `app.config.get_settings() -> Settings`（`functools.lru_cache`）。
  - `app.db.connect(settings: Settings) -> None`：建立模組層級的 `AsyncMongoClient(settings.mongodb_uri, serverSelectionTimeoutMS=5000)`。
  - `app.db.close() -> None`（async）：關閉 client。
  - `app.db.get_db() -> AsyncDatabase`：回傳 `client[settings.mongodb_db]`；還沒連線時丟 `RuntimeError`。之後的搬遷都用這個函式取得資料庫。
  - `app.db.is_db_ready() -> bool`（async）：對 `admin` 執行 `ping`；client 為 None 或發生 `PyMongoError` 時回 False。
  - `app.responses.ok(data) -> dict`：回傳 `{"success": True, "data": data}`。
  - `app.responses.fail(status_code: int, message: str) -> JSONResponse`。
  - `app.responses.register_error_handlers(app: FastAPI) -> None`。
  - `app.main.app`：`FastAPI(title="Pet Haven API", docs_url="/api-docs", openapi_url="/api-docs.json", lifespan=...)`。

def test_settings_ignore_unknown_keys(tmp_path):
    env = tmp_path / ".env"
    env.write_text("MONGODB_URI=mongodb://x\nJWT_SECRET=abc\nNODE_ENV=development\n", encoding="utf-8")
    s = Settings(_env_file=env)
    assert s.mongodb_uri == "mongodb://x"

def test_settings_require_mongodb_uri(monkeypatch):
    monkeypatch.delenv("MONGODB_URI", raising=False)
    with pytest.raises(ValidationError):
        Settings(_env_file=None)

def test_cors_origin_list_strips_spaces(monkeypatch):
    monkeypatch.setenv("CORS_ORIGINS", "http://a:3000, http://b:3000,")
    assert Settings(_env_file=None).cors_origin_list() == ["http://a:3000", "http://b:3000"]

`test_health.py`：

```python
def test_health_ok(client):
    r = client.get("/api/health")
    assert r.status_code == 200
    assert r.json() == {"success": True, "data": {"status": "ok"}}

def test_ready_when_db_up(client):
    app.dependency_overrides[is_db_ready] = lambda: True
    r = client.get("/api/ready")
    assert r.status_code == 200
    assert r.json() == {"success": True, "data": {"status": "ready"}}

def test_ready_when_db_down(client):
    app.dependency_overrides[is_db_ready] = lambda: False
    r = client.get("/api/ready")
    assert r.status_code == 503
    assert r.json() == {"success": False, "message": "資料庫無法連線"}

async def test_is_db_ready_false_on_error(monkeypatch):
    # 假 client：client.admin.command("ping") 丟出 ServerSelectionTimeoutError
    monkeypatch.setattr(db, "_client", FakeClientRaising())
    assert await db.is_db_ready() is False

async def test_is_db_ready_false_when_not_connected(monkeypatch):
    monkeypatch.setattr(db, "_client", None)
    assert await db.is_db_ready() is False

def test_swagger_served(client):
    assert client.get("/api-docs").status_code == 200
    assert client.get("/api-docs.json").json()["info"]["title"] == "Pet Haven API"

def test_cors_preflight_allows_frontend(client):
    r = client.options("/api/health", headers={
        "Origin": "http://localhost:3000", "Access-Control-Request-Method": "GET"})
    assert r.headers["access-control-allow-origin"] == "http://localhost:3000"
```

### Task 5：用 Atlas 實測

需要組員自己的 `backend/.env`（Task 1 已搬回）。這個 Task 不改程式。

- [ ] **Step 1：請使用者確認 `.env`**

請使用者確認 `backend/.env` 裡有完整的 `MONGODB_URI`（`mongodb+srv://...`）和 `MONGODB_DB`，而且自己的 IP 已加進 Atlas Network Access。**不要讀取 `.env`。**

- [ ] **Step 2：啟動並檢查**

先執行 `npm run dev:backend`，再依序執行：
1. `curl -i http://localhost:5000/api/ready`。Expected：200，`{"success":true,"data":{"status":"ready"}}`
2. 在瀏覽器開 `http://localhost:5000/api-docs`。Expected：看到 Swagger，裡面有 System 的兩支 API。
3. `npm run test:backend`。Expected：全部 passed。

回 503 時看伺服器 log，依序檢查 IP 白名單、帳密、連線字串格式。回報給使用者時不要貼出連線字串。

- [ ] **Step 3：回報**

在 PR 說明記錄 Task 5 的結果。同時寫明前端在 auth、pets、adoptions 搬完之前只能用 mock 模式。
