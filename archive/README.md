# 歷史快照

此目錄保留整理前的程式備份、修復筆記與依賴清單，便於比對。快照不是目前程式的啟動入口，且可能引用舊路徑或舊設定。

- snapshots/backend：server.js、seed.js 與 auth 路由的舊版本。
- snapshots/frontend：package.json、ProfilePage 與 tabs-fix 筆記。
- snapshots/before-fix-*.txt：歷史依賴清單。

搬移清單與原始 SHA-256：[organization-moves.json](../docs/organization-moves.json)。新的改動請透過 Git 保存，避免增加散落的備份檔。
